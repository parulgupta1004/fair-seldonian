# Security Policy

## Supported Versions

Following versions are security supported:

| Version | Supported          |
| ------- | ------------------ |
| >= 3.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you believe you’ve found a security vulnerability, please report it directly to @parulgupta1004.

Provide enough detail for us to reproduce and assess the issue, including affected versions, reproduction steps or a proof of concept, and any relevant logs or screenshots.

### Response & Remediation SLA
We aim to:

- Acknowledge your report within 2 business days.
- Assess and triage the vulnerability within 4 business days.
- Provide an initial remediation plan or status update within 5 business days.
- Release a fix according to severity and complexity, with critical vulnerabilities prioritized for expedited remediation.

Please allow us reasonable time to investigate and fix reported issues before publicly disclosing them. We appreciate responsible disclosure and will keep reporters informed throughout the process.
