The API reference now documents only the public API. Every module declares `__all__`, so autodoc renders the 59 names users are meant to call instead of all 87 public-looking symbols — 28 internal helpers such as `eval_hoeffding`, `ghat_base` and `annotate_sides` are no longer listed. Long signatures wrap one parameter per line, so `SeldonianConfig` is a readable list of options rather than a 227-character run-on, and `DEFAULT_CONFIG` is documented for the first time. by @parulgupta1004
