`equal_opportunity` and `equalized_odds` now emit rate primitives: `equal_opportunity(0.1)` returns `"TPR(1) TPR(0) - abs 0.1 -"` rather than the ratio form. The quantity is the same, but without a division both definitions stay inside the affine fragment. Code that pattern-matches on the returned string will see the difference; `demographic_parity`, `error_rate` and `error_rate_parity` are unchanged. by @parulgupta1004
