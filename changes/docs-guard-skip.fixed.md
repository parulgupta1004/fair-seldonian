`tests/test_docs_sync.py` no longer errors when only the `dev` extra is installed. Loading the Sphinx extension needs docutils, which arrives with the `docs` extra, so twelve tests raised `ModuleNotFoundError` instead of skipping — including on CI's test matrix. They skip now; the docs workflow installs `.[dev,docs]` and runs the file there, so the guards still execute. by @parulgupta1004
