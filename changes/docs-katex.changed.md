Math is pre-rendered with KaTeX at build time instead of typeset by MathJax in the browser, removing a 974 KB (274 KB gzipped) download from every page carrying an equation, along with the reflow while it ran. A test renders every expression with errors enabled, since `sphinxcontrib-katex` pre-renders with `throwOnError` off and would otherwise bake an unparseable one into the page as error text. by @parulgupta1004
