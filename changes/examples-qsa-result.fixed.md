The shipped examples, README, quickstart docs and notebooks still unpacked `QSA` as a three-tuple and so failed with `ValueError: too many values to unpack` after it began returning `QSAResult`. All call sites now use the result object, and `tests/test_examples.py` executes every script in `examples/` so a public signature change cannot break them silently again. CI lint also now covers `scripts/` and `examples/`, not just `src/` and `tests/`. by @parulgupta1004
