Added ready-to-use fairness constraint builders — `demographic_parity`, `equal_opportunity`, `equalized_odds`, `error_rate`, and `error_rate_parity` (in `fair_seldonian.constraints.fairness`, re-exported at the top level). Each returns the postfix constraint string for a given tolerance `epsilon` and group(s), so common fairness definitions can be passed straight to `SeldonianConfig` without hand-writing the notation. Documented with descriptions, references, and a summary table in the docs.
