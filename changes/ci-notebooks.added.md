CI now executes the example notebooks and checks that the package imports on a base install. The notebook tests already existed but used `pytest.importorskip("nbclient")`, and nbclient reached the environment only transitively through JupyterLab — which CI never installed — so they skipped silently and reported green. A new `notebook-test` extra declares `nbclient`, `nbformat`, `ipykernel` and `matplotlib` directly; the `notebooks` job asserts those imports before running pytest, so a broken install fails loudly instead of skipping. A separate `packaging` job installs the built wheel with no extras at all and imports the public API from outside the source tree, which is the check that would have caught `fair_seldonian.experiments` needing matplotlib merely to import. by @parulgupta1004
