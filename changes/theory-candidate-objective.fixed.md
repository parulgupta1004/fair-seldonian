The theory page described candidate selection as a hard barrier — `f(theta)` when feasible, `-C - g_hat` otherwise, with `C` defaulting to 10,000. That is the formulation the code was changed *away from*: the barrier put the objective at order 1e4, and Powell's relative convergence test then reported success after one iteration while still infeasible. It now documents the continuous penalty actually minimised, `log_loss + penalty * max(0, g_hat)`, without hardcoding a default that can drift. by @parulgupta1004
