Added `PR(g)` and `NR(g)`, the predicted-positive and predicted-negative rates, as base variables. Both ignore the label — `PR(g)` is `TP(g) + FP(g)` — so like the cells they are means over the whole group. `demographic_parity` now emits `"PR(1) PR(0) - abs 0.1 -"` rather than the four-cell form. The quantity is unchanged, but every leaf spends its own slice of `delta`, so halving their number tightens the bound: on a 20,000-row demographic-parity problem the Hoeffding bound drops from 0.06415 to 0.02808, and the t-test bound from 0.02390 to 0.01078. Both now sit below the reference Seldonian Toolkit's equivalents (0.02960 and 0.01307), which had the advantage of a `PR` base node all along. In the affine path `PR`/`NR` expand back onto the cell basis, so each conditioning set stays spanned by a genuine partition. by @parulgupta1004
