Search no longer blocks page rendering. pydata-sphinx-theme injects `searchtools.js`, `language_data.js` and `searchindex.js` into `<head>` on every page with no loading attribute, so the browser stopped parsing to fetch and run ~103 KB of JavaScript before painting, whether or not the reader used search; a template override defers all three, cutting render-blocking JavaScript from 133 KB to 30 KB (32 KB to 11 KB gzipped). Results now also appear as you type instead of requiring a full page load of `search.html`. by @parulgupta1004
