The introduction listed four base variables described as "rates" — `TP(g)` is a cell, a fraction of the whole group, not a rate — omitted the six rate and predicted-rate primitives, and said the framework supports two concentration inequalities when there are four. Both tables are now generated from the package, and a test fails when a written-out count disagrees with the code. It also no longer calls the default constraint a form of equal opportunity: that criterion compares `TPR`, and the default compares cells. by @parulgupta1004
