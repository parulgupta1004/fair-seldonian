**Candidate selection stopped after one iteration while still infeasible.** The barrier `-10000 - u` put the objective at order 1e4, and Powell's convergence test is *relative*, so the default `ftol=1e-4` gave a stopping threshold near 1.0 while `u` varies by only ~1e-2 across the parameter space; `maxiter` never bound. Replaced with the exact penalty `log_loss + penalty * max(0, u)`, configurable via the new `SeldonianConfig.penalty`. by @parulgupta1004
