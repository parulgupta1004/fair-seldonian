Removed the machine-specific paths from the repository. The three `toolkit_comparison_*` scripts passed data to each other through hardcoded `/tmp/h2h_*` files; they now use `exp/h2h/` resolved relative to the script, which is already gitignored, and each script's docstring states the order they must run in. `.coverage` is no longer tracked: it is a SQLite artifact regenerated by every `pytest --cov` run, read by nothing, and it embedded 31 absolute paths to the machine that last ran the suite. It is now gitignored along with `.coverage.*`. by @parulgupta1004
