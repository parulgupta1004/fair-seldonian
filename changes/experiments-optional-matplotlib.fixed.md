`import fair_seldonian.experiments` raised `ModuleNotFoundError: No module named 'matplotlib'` on any install without the `plots` or `notebook` extra — including a base `pip install fair-seldonian` and CI, which installs only `dev`. The subpackage re-exports `plot_all`, and `plots.py` imported matplotlib at module level, so pulling in `summarise`, `run_study` or `clopper_pearson` dragged an optional plotting dependency with it. pyplot is now imported on first use inside the plotting functions, and a test asserts the subpackage imports with matplotlib made unavailable. by @parulgupta1004
