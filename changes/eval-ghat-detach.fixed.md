`eval_ghat` returned a tensor still attached to the autograd graph, so any caller doing `float(eval_ghat(...))` on a model from `simple_logistic` — which sets `requires_grad=True` — got a spurious "converting a tensor with requires_grad to a scalar" warning. A bound is a number, and nothing in the library differentiates through one (candidate selection uses derivative-free Powell), so it is now detached at the public boundary, as is the per-sample vector inside the affine path. by @parulgupta1004
