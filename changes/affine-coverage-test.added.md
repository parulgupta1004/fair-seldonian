Added an empirical coverage test for the affine bound. It was previously checked only by a single `bound >= truth` assertion on one dataset, which says little about the rate — and affine is the tightest path shipped, so an error there is the least likely to look like anything other than a pleasingly small number. The test is built to be able to fail: the group base rates differ, so the true value sits away from the kink of `abs` where the estimator is biased upward, and the rates sit near 1/2 so Hoeffding's a-priori range is close to the observed variance. Halving the half-width drops Hoeffding's coverage to 0.90. by @parulgupta1004
