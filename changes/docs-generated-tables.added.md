Documentation tables are now generated from the package at build time by a Sphinx extension in `docs/_ext/`. The fairness-constraint table calls each builder and reports the postfix string it actually emits, its leaf count and whether it compiles to affine forms; the inequality table computes each half-width on a fixed sample; the variant and base-variable tables read the registries. Hand-transcribed tables had already drifted from the code. by @parulgupta1004
